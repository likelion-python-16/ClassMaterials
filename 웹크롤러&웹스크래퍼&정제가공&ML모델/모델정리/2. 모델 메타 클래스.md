모델에 대한 메타정보(정보에 대한 정보)”를 담는 클래스입니다.
모델이 "어떻게 저장될지, 어떻게 보일지, 어떤 규칙을 가질지" 정해주는 설정 모음

```python
class Menu(models.Model):
    name = models.CharField(max_length=100)

    class Meta:
        db_table = "menu"  # 테이블 이름을 "menu"로 하자!
        verbose_name = "메뉴"  # 관리자에서 예쁘게 보이게!
```

Django는 모델 이름이 아니라  
“앱이름 + 모델이름” 조합으로 DB 테이블 이름을 자동으로 만듭니다.
db_table = "menu"를 주면 테이블 이름이 menu로 바뀝니다.

- **역할**: 실제 DB에서 이 모델의 테이블 이름을 직접 지정할 수 있어요.
- 예: `db_table = "products"` → 실제 DB 테이블명이 `products`로 생성됨


![[Pasted image 20250706084537.png]]
- **역할**: 두 개 이상의 필드를 묶어서 인덱스를 생성해 성능을 올려요.
- 예: `["driver", "restaurant"]` → 이 두 필드를 자주 같이 검색할 때 유리함


![[Pasted image 20250706084548.png]]
- **역할**: 두 개 이상의 필드를 묶어서 중복 없이 유일하게 유지해요.
- 예: 한 `driver`가 동일한 `restaurant`에 중복해서 등록되지 않도록 막는 용도


![[Pasted image 20250706084602.png]]
- **역할**: 보다 복잡한 제약 조건(조건부 유일성, 값 범위 등)을 직접 설정할 수 있어요.
- 예시:
    - `username + country` 조합이 유일해야 함
    - `age`는 0 이상 120 이하만 가능
