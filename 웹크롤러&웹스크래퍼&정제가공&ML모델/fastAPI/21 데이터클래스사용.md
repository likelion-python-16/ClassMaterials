Data Class란?
	Python의 `@dataclass`는 데이터 저장용 클래스를 짧고 간단하게 만들 수 있도록 도와주는 기능입니다.
- 원래 클래스는 `__init__`, `__repr__`, `__eq__` 같은 메서드를 직접 작성해야 했습니다.
- 그런데 `@dataclass`를 붙이면, 그런 귀찮은 코드를 자동으로 만들어줍니다!

예시로 이해해보기 일반 클래스 (귀찮음)
```python
class Item:
    def __init__(self, name, price):
        self.name = name
        self.price = price

    def __repr__(self):
        return f"Item(name={self.name}, price={self.price})"
```

Data Class (간단함!)
```python
from dataclasses import dataclass

@dataclass
class Item:
    name: str
    price: float
```
자동으로 `__init__`, `__repr__` 등이 생성돼요.

왜 필요한가?
`코드 간결함` :	__init__, __repr__ 안 써도 됨
`테스트 쉬움` :	비교, 출력, 변환이 편리
`가독성 좋음` :	순수 데이터 구조를 깔끔하게 표현
`자동 기능` :	타입 힌트 + 기본값 + 비교 연산 다 자동 제공

기본 Data Class 예제
`Book`이라는 데이터 객체를 쉽게 생성하는 방법
```python
from dataclasses import dataclass

@dataclass
class Book:
    title: str
    author: str
    price: float

book = Book("데이터 클래스란?", "이상한 나라의 코딩", 15.99)
print(book)
```

Data Class + 기본값 지정
```python
from dataclasses import dataclass

@dataclass
class Product:
    name: str
    price: float = 0.0
    in_stock: bool = True

item = Product("USB")
print(item)
```
- `price`와 `in_stock` 필드에 기본값을 줄 수 있습니다.
- `Product("USB")`라고만 입력해도 나머지는 기본값이 자동으로 채워집니다.

Data Class를 FastAPI 요청 데이터로 사용
```python
from dataclasses import dataclass
from typing import Union
from fastapi import FastAPI

app = FastAPI()

@dataclass
class Item:
    name: str
    price: float
    description: Union[str, None] = None

@app.post("/items/")
async def create_item(item: Item):
    return item
```
- `@dataclass`를 요청 바디 모델로 사용하면 FastAPI가 자동으로 JSON → 객체로 변환해줍니다.
- Swagger에서 POST 요청 테스트도 가능.

Data Class를 FastAPI 응답 모델로 사용
```python
from dataclasses import dataclass, field
from typing import List, Union
from fastapi import FastAPI

app = FastAPI()

@dataclass
class Item:
    name: str
    price: float
    tags: List[str] = field(default_factory=list)
    description: Union[str, None] = None

@app.get("/items/", response_model=Item)
async def get_item():
    return {
        "name": "Python 책",
        "price": 29.99,
        "description": "초보자를 위한 FastAPI",
        "tags": ["프로그래밍", "API"]
    }
```
- 응답 형식도 `@dataclass`로 명시하면 FastAPI가 자동으로 스키마를 생성합니다.
- `field(default_factory=list)`는 기본값으로 빈 리스트를 줍니다.

중첩된 Data Class 응답
```python
from dataclasses import dataclass, field
from typing import List, Union
from fastapi import FastAPI

app = FastAPI()

@dataclass
class Book:
    title: str
    description: Union[str, None] = None

@dataclass
class Author:
    name: str
    books: List[Book] = field(default_factory=list)

@app.get("/authors/", response_model=List[Author])
def get_authors():
    return [
        {
            "name": "이정수",
            "books": [
                {"title": "Python 개론", "description": "입문자를 위한 책"},
                {"title": "FastAPI 완전정복"}
            ]
        }
    ]
```
- `Author` 안에 `Book` 리스트가 들어있는 구조로, 중첩된 JSON 응답을 구현합니다.
- 복잡한 모델도 `@dataclass`를 활용해 간결하게 표현할 수 있습니다.
